## Decisions applied

### Implemented publicly

- Visible AURA/UPWARD explainer on the main page
- Revised five-phase AURA public model
- Dedicated architecture page
- Dedicated submission-guidelines page
- Dedicated review-process page
- Clear ClickUp form CTA
- AURA = operational / intake / review / lifecycle / governance
- UPWARD = synthesis / integration / institutional memory

### Held back from public copy

- Detailed scoring weights
- Minimum score thresholds
- Donor access/confidentiality mechanics
- Reviewer identities or internal committee routing
- New or replacement public Research Readiness Levels explanation
- Unapproved new governance language

## Public copy principle

The public site should be accurate, usable, and serious without publishing the internal machinery. It should help researchers submit better proposals and help partners understand SUAPS's research discipline, while keeping sensitive review details inside ClickUp/internal documentation.
